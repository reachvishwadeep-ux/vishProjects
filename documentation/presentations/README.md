# MatchSnap presentations

## India concept and execution plan — Version 1

`MatchSnap_India_Concept_and_Execution_Plan_v1.pptx` contains the initial
India-first concept, product workflow, safety model, pilot roadmap and funder
readiness plan.

Regenerate the PowerPoint from the repository root:

```bash
.venv/bin/pip install python-pptx==1.0.2
.venv/bin/python documentation/presentations/generate_matchsnap_india_v1.py
```

The deck is a planning document. It does not claim production readiness, legal
compliance, government approval or recognition accuracy.
